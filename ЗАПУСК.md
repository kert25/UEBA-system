# Запуск UEBA-системы

## Первый запуск (один раз)
```bash
cd ueba-system
make setup       # venv + данные + модель
make all         # build + start + pipeline
```

## Последующие запуски
```bash
cd ueba-system
docker-compose up -d
make pipeline
```

## Если что-то пошло не так (перезапуск с чистой ES)
```bash
docker-compose down -v && docker-compose up -d
make pipeline
```

## Остановить
```bash
docker-compose down
```

## Проверить, что всё работает
```bash
for p in 8001 8002 8003 8004 8005 8006; do
  curl -sf http://localhost:$p/health && echo ":$p OK" || echo ":$p FAIL"
done
```

## Другое
```bash
make test        # тесты с покрытием
make lint        # линтер
make clean       # полный сброс (venv + данные + модель + докер)
```
